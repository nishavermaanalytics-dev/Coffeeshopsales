# ☕ Coffee Shop Sales Dashboard | Excel Data Analytics Project

## 📌 Project Overview

This project is an interactive Coffee Shop Sales Dashboard created in Microsoft Excel to analyze sales performance, customer purchasing behavior, and product trends.

The dashboard provides visual insights into:

* Total sales performance
* Order trends
* Product category analysis
* Monthly and weekly sales comparison
* Peak business hours
* KPI metrics

Interactive slicers allow users to dynamically filter dashboard data by month and weekday.
